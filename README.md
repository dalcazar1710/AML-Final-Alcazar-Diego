# AML Final Project – Employee Attrition Forecasting #

Author:
Diego Alcázar

Course:
Advanced Machine Learning

Project Description:

This project simulates a large-scale HR dataset for a tech company and builds a forecasting model to predict monthly employee attrition.

The objective is to demonstrate the design of an end-to-end Machine Learning pipeline including data generation, preprocessing, modeling, evaluation, and visualization.

The notebook is designed to run in Google Colab in a few minutes without requiring GPU resources.

Repository Structure:

cuadernos/ → Notebook containing the full ML pipeline

datos/ → Generated synthetic datasets

resultados/ → Model outputs and visualizations

informe/ → Project report (if required)

How to Run:

Open the notebook in Google Colab

Run all cells sequentially

Results will be generated automatically

Requirements:

Python 3.9+
pandas
numpy
scikit-learn
matplotlib
